PARE System
User Manual

A comprehensive, step-by-step guide to navigating and utilizing the PARE System's portals effectively.

Page Landing / Login Page

Description: The landing and login page is a crucial feature of the PARE system. It serves as the gateway for users to access the platform's core functionalities, enabling passengers, drivers, and admins to securely log into their respective portals. Without signing in, users would not be able to fully interact with or benefit from the system, making it an integral part of the entire PARE experience.
[Screenshot of Landing/Login Page]
  1. This is the text field where the user inputs their registered Email Address or ID Number.
  2. This is the text field where the user inputs their password.
  3. This button allows the user to log in to the system after entering their credentials.
  4. This link redirects the user to the registration form to create a new account.
  5. This link allows the user to regain access to their account if they forgot their password.

Form Account Recovery & Password Reset Form

Description: The Password Recovery Form is a crucial maintenance feature of the PARE system, providing users with a secure and automated method to regain access to their accounts if credentials are forgotten. It verifies the account email and sends a secure authorization link to establish a new password.
[Screenshot: Forgot Password Screen with numbered callout circles 1–3]
  1. This is the text field where the user inputs their registered email address to locate their account.
  2. This button generates and sends a secure password reset link to the provided email address.
  3. This link redirects the user back to the primary sign-in screen.

Form Registration Form

Description: The registration form allows commuters to create an account for the PARE system. It provides options for Regular and Discount accounts, ensuring that eligible passengers can apply for special fare rates by submitting the necessary identification documents.
[Screenshot of Registration Form]
  1. This option allows the user to select their account type: Regular Account or Discount Account.
  2. This upload field allows users applying for a discount to capture or upload a clear photo of a valid ID.
  3. These text fields are for entering personal details such as Name, Address, and Emergency Contact Information.
  4. This text field is for entering the 6-digit OTP (One-Time Password) verification code sent to the user's email.
  5. This button submits the registration form and creates the account.

Page Passenger Dashboard & Live Map

Description: The Passenger Dashboard is a central hub for commuters. It provides access to real-time bus tracking via the Live Map, allowing passengers to view active buses. It also includes a trip history section for reviewing past rides and managing their profile.
[Screenshot of Passenger Dashboard & Map]
  1. This tab opens the Live Map interface, enabling the tracking of active buses in real-time.
  2. These indicators (e.g., pulsing orange dots) on the map represent active buses currently on their routes.
  3. This feature allows the user to click on a bus indicator to view the specific bus body number and current location.
  4. This tab opens the "My Rides" section, displaying a historical log of completed trips, including date, time, and fare deducted.

Page Driver Portal

Description: The Driver Portal is optimized for mobile devices, allowing drivers to operate the system effortlessly while in the vehicle. It provides essential tools for starting and ending shifts, tracking GPS routes, and processing passenger tickets.
[Screenshot of Driver Portal]
  1. This dropdown list allows the driver to select their specific route for the current shift.
  2. This button starts the trip, activating the vehicle's GPS location so passengers can track the bus on the Live Map.
  3. This scanner tool allows the driver to scan passenger tickets or QR codes upon boarding to process fares.
  4. This button ends the trip, deactivating the live tracking and finalizing the shift log and earnings.

Page Admin Portal & Settings

Description: The Admin Portal serves as the central command center for fleet operators. It is used to monitor revenue, configure system-wide fare rules, and manually approve or reject discount applications submitted by passengers.
[Screenshot of Admin Portal]
  1. This tab navigates the administrator to the Fare Settings configuration page.
  2. These text fields allow the admin to enter and update the Base Fare and Succeeding Kilometer Rate.
  3. These configuration fields are used to set the percentage discounts for Seniors, PWDs, and Students.
  4. This section displays passengers with "Pending Approval" status for their discount applications.
  5. This button opens the uploaded ID document for the admin to review its validity.
  6. These buttons allow the admin to either Approve or Reject the discount application based on the provided ID.
